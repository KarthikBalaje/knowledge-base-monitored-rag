Case Study 3: observable, guarded RAG for Data Science, Machine Learning,
Deep Learning, PyTorch, TensorFlow and NLP.

dense + BM25 hybrid retrieval -> Ollama -> answer, with Arize Phoenix observability.

Phoenix Tracing 15, Evaluation Evidence 15. Total 100.
